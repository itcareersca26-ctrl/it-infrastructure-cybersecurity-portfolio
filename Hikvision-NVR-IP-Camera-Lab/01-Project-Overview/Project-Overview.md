Hikvision NVR \& IP Camera Lab



1\. Project Overview



This project is part of my home IT lab, where I worked on configuring and troubleshooting a Hikvision NVR and IP camera surveillance system.



I used Windows PowerShell, Hikvision HiTools, and iVMS-4200 to check network connectivity, manage camera devices, and investigate communication problems.



The project helped me gain hands-on experience with IP addressing, subnetting, PoE networking, DNS, and network troubleshooting.



2\. Project Objectives



My main goals for this project were:



Configure and access the Hikvision NVR through my home network.



Verify that the connected IP cameras were online.



Configure DNS so I could access the NVR using a hostname.



Test network connectivity using PowerShell.



Understand how IP cameras communicate across different subnets.



Investigate why the door station was not connecting to the NVR.



Document the configuration, testing, and troubleshooting results.

5\. Project Results



I successfully accessed the Hikvision NVR through my home network and verified that three outdoor cameras were online and displaying live video.



I configured DNS resolution for the NVR and tested network connectivity using PowerShell.



I also investigated a network communication issue involving the door station and the NVR. The door station works with the indoor monitor, but it is not currently accessible through the NVR camera channel.



I decided to leave the working system unchanged and document the remaining issue for future troubleshooting.
