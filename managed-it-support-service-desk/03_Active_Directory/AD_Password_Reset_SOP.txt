CONTOSO CONSULTING
ACTIVE DIRECTORY PASSWORD RESET SOP
========================================

SOP ID: SOP-AD-001
Category: Active Directory
Priority: Standard User Support

PURPOSE
-------
Provide a standardized procedure for assisting users who have
forgotten their password or are unable to authenticate.

PRE-RESET VERIFICATION
----------------------
1. Confirm the user's identity according to company verification
   procedures.
2. Confirm the user account and username.
3. Confirm the user is authorized to receive assistance.
4. Check whether the account is disabled or locked.
5. Review the ticket for previous related incidents.

PASSWORD RESET PROCEDURE
------------------------
1. Locate the user account in Active Directory.
2. Verify the correct user account.
3. Reset the password according to company policy.
4. Do not record or store the user's password in the ticket.
5. Require the user to change the temporary password at next login
   when company policy requires it.
6. Confirm the user can authenticate successfully.

POST-RESET VALIDATION
---------------------
1. Confirm successful authentication.
2. Confirm the account is not locked.
3. Verify required access remains available.
4. Document the action taken in the ticket.
5. Close the ticket after confirming resolution.

SECURITY REQUIREMENTS
---------------------
- Never request or record a user's permanent password.
- Verify identity before performing account changes.
- Follow least-privilege principles.
- Do not make unauthorized group membership changes.
- Escalate suspicious or unauthorized access requests.
- Document all administrative actions.

ESCALATION
----------
Escalate to a senior administrator or security team when:
- Identity cannot be verified.
- The account appears compromised.
- Unauthorized access is suspected.
- Privileged administrator credentials are involved.
- Multiple accounts are unexpectedly affected.
- The issue appears to be caused by a domain-wide problem.
