1. PROJECT OVERVIEW
-------------------
This project demonstrates a practical IT support and service-desk
environment using Windows Server, Active Directory, file services,
networking, PowerShell, virtual machines, ticketing, documentation,
and troubleshooting procedures.

2. TROUBLESHOOTING
------------------
The lab includes practical troubleshooting activities involving:
- Windows systems
- Network connectivity
- DNS resolution
- File-share access
- NTFS permissions
- User authentication
- Server access

Troubleshooting was performed using PowerShell and Windows
administration tools.

3. NETWORKING AND FILE SERVICES
-------------------------------
The lab includes SMB file sharing and NTFS permission management.

The HOME-FILE01 server provides shared storage for lab projects.
Permissions were configured to control access to specific users and
groups.

Access was tested using network paths and PowerShell commands.

4. VIRTUAL MACHINES
-------------------
The lab uses Hyper-V virtual machines to provide a controlled
infrastructure environment.

Virtual machines used include:
- HOME-DC01
- HOME-FILE01
- HOME-TEST01

VM status and resource information were verified using Hyper-V
PowerShell commands.

- Priority classification
- Troubleshooting
- Resolution tracking
- Ticket lifecycle management

Priority levels documented include:
Low, Medium, High, and Critical.
