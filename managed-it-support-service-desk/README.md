# Managed IT Support & Service Desk Lab

## Project Overview

This project demonstrates hands-on IT support and service desk administration in a simulated business environment.

The lab combines Active Directory administration, Windows troubleshooting, networking, SMB file services, user onboarding and offboarding, ticket documentation, incident response, PowerShell, knowledge-base documentation, and standard operating procedures.

The project was developed using an authorized personal home-lab environment and simulated business scenarios.

> Personal names, credentials, private IP addresses, and sensitive infrastructure information have been sanitized from the public version of this project.
