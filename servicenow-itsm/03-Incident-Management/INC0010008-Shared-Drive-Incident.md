# ServiceNow Incident Management Lab

## Incident: INC0010008

### Project Objective

This lab demonstrates the creation and management of an IT incident using ServiceNow. The goal is to simulate a real IT Service Desk workflow from reporting through assignment, troubleshooting, and resolution.

### Incident Details

- Incident Number: INC0010008
- Caller: Joe Employee
- Short Description: Unable to access shared network drive
- Category: Network
- Subcategory: None
- Channel: Self-service
- State: In Progress
- Impact: 2 - Medium
- Urgency: 2 - Medium
- Priority: 3 - Moderate
- Assignment Group: Network
- Assigned To: David Loo

### Description

The user reported being unable to access the shared network drive required for normal work duties. Troubleshooting is required to determine whether the issue involves network connectivity, permissions, or the file server.

### Business Reasoning

**Impact: 2 - Medium**

The issue prevents the employee from accessing a required resource but does not appear to affect the entire organization.

**Urgency: 2 - Medium**

The employee requires access to continue normal work, but the issue is not currently a critical outage.

**Priority: 3 - Moderate**

The priority was determined from the Medium impact and Medium urgency.

### Assignment

The incident was assigned to the Network support group and then assigned to technician David Loo for investigation.

### Current Incident Workflow

Employee reports issue  
→ Incident created  
→ Categorized as Network  
→ Impact and urgency assessed  
→ Priority established  
→ Assigned to Network support  
→ Assigned to David Loo  
→ State changed to In Progress  
→ Work Note added  
→ Investigation in progress

### Troubleshooting

The technician began investigating the shared network drive issue. Initial troubleshooting will check:

- Network connectivity
- User permissions
- Shared-drive accessibility
- File server availability

Further troubleshooting is required before the incident can be resolved.

### Skills Demonstrated

- ServiceNow navigation
- Incident creation and categorization
- Impact, urgency, and priority management
- Assignment group and technician assignment
- Work Notes
- Incident state management
- ITSM incident lifecycle
- Service Desk documentation

### Resolution

The incident has not yet been resolved.
