# Windows Server & Active Directory

## Project Overview

This project documents the design, configuration, and testing of a Windows Server infrastructure environment using Active Directory Domain Services (AD DS), DNS, organizational units, user accounts, security groups, and Group Policy.

The environment was built as part of a hands-on home lab to develop practical infrastructure, administration, networking, and cybersecurity skills.

---

## Environment

| Component | Role |
|---|---|
| HOME-DC01 | Domain Controller / Active Directory / DNS |
| HOME-FILE01 | Windows File Server / SMB |
| HOME-TEST01 | Windows Test Client |
| HOME.LOCAL | Active Directory Domain |
| Hyper-V | Virtualization Platform |
| Windows Server | Server Operating System |
